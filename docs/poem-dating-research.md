# 诗歌系年数据调研

静夜思等唐诗的"创作年份"在 CBDB 中查不到，因为 CBDB 的粒度是"人物"和"文集"，不是"单首诗"。本文档调研现有数据源的系年能力。

---

## 一、CBDB 的文献体系

CBDB 的 TEXT_CODES 表存储的是"书/文集"级别（61,070 部），不是单首诗：

| 表 | 粒度 | 有无系年 |
|---|---|---|
| TEXT_CODES | 文集（如《李太白集》） | c_text_year 字段存在但大量为 null |
| BIOG_TEXT_DATA | 人物↔文集关联 | c_year 为 -1 或 null |
| TEXT_INSTANCE_DATA | 文集版本/刊本 | 出版年 c_pub_year，非创作年 |

以李白为例，CBDB 只记录了 4 部文集（李太白集、李翰林集、草堂集等），无单首诗记录。**静夜思不在 CBDB 中**。

CBDB 适合回答"某人在某年去了某地任某职"，但无法回答"某首诗写于某年"。

## 二、GitHub 开源项目

### 2.1 chinese-poetry（45k+ stars）

- 仓库：https://github.com/chinese-poetry/chinese-poetry
- 内容：5.5 万首唐诗 + 26 万首宋诗 + 2.1 万首宋词
- 格式：JSON
- **无系年字段**：数据结构为 `{title, author, paragraphs}`，无创作年份

### 2.2 其他数据库

| 项目 | 规模 | 有无系年 |
|------|------|---------|
| [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) | 30 万首 | 无 |
| [PoetryLibrary](https://github.com/yaonphy/PoetryLibrary) | 82 万首 | 无 |
| [chinese-poem-analysis](https://github.com/gintian/chinese-poem-analysis) | 10 万首 | 有"考证"文本字段（非结构化） |
| [GuWen](https://github.com/lhw828/GuWen) | 多种古籍 | 无 |

**结论：GitHub 上无结构化的诗歌系年数据库。**

## 三、学术资源（非 GitHub）

### 3.1 王兆鹏团队 — 唐诗编年系地信息数据库

王兆鹏（中南民族大学教授）及其团队从以下来源系统提取唐诗的编年与系地信息：

- 《全唐诗》《全唐文》作家小传
- 《中国文学家大辞典·唐代卷》
- 历代年谱及生平考证论著
- 彭庆生《唐诗系年》

该团队制作的数据库是**目前最系统的唐诗系年数据源**，但**未公开开源**。部分成果体现在：

- 《唐诗排行榜》（2012，中华书局）— 含大量系年考证
- 《唐宋文学编年地图》— 数字人文平台，可查询某诗人某年在某地写了哪些诗

### 3.2 北京大学 — 全唐诗分析系统

- 基于全唐诗开发的学术检索系统
- 包含作者、体裁、主题等分析功能
- 属于商业/学术系统，数据未完全开放

### 3.3 传统学术著作（纸质）

如需某位诗人的系年考证，最可靠的来源是：

| 著作 | 作者 | 覆盖范围 |
|------|------|---------|
| 《唐诗系年》 | 彭庆生 | 全唐诗 |
| 《钱注杜诗》 | 钱谦益 | 杜甫 |
| 《苏轼诗集》编年部分 | 王文诰等 | 苏轼 |
| 《白居易集笺校》 | 朱金城 | 白居易 |
| 《玉溪生年谱会笺》 | 张采田 | 李商隐 |

## 四、可行的自建方案

如果项目需要诗歌系年数据，有以下路径：

### 方案 A：人工标注（小规模）

唐诗三百首只有 310 首（卷11 扩展后约 511 首），可参考上述学术著作逐首标注创作年份。工作量约 2-3 天。

输出格式：
```json
{
  "静夜思": { "author": "李白", "year": 726, "place": "扬州", "source": "詹锳《李白诗文系年》" }
}
```

### 方案 B：CBDB 间接推断

利用 CBDB 的诗人行迹数据间接推断：

1. 查李白的 BIOG_ADDR_DATA → 获得地点时间线
2. 查李白的 POSTED_TO_OFFICE_DATA → 任职时间
3. 结合诗歌内容中的地名/事件推断创作年份

例如：李白 726 年在扬州（CBDB 有地址记录），《静夜思》学界普遍认为作于此时期。

### 方案 C：LLM 辅助标注

用大语言模型参考学术文献进行批量标注，人工校验。准确率需要人工复核，但可以大幅加速。

## 五、总结

| 数据源 | 系年精度 | 可得性 | 适用场景 |
|--------|---------|--------|---------|
| CBDB | 无（仅人物级别） | 开源 | 诗人生平行迹 |
| chinese-poetry | 无 | 开源 | 诗歌文本 |
| 王兆鹏团队数据库 | 精确到年 | 未开源 | 学术研究 |
| 传统学术著作 | 精确到年 | 纸质/电子书 | 人工标注参考 |
| 自建标注 | 精确到年 | 自主可控 | 项目定制 |

**建议**：对于唐诗三百首的规模（511 首），方案 A（人工标注）最可行。参考彭庆生《唐诗系年》和王兆鹏团队成果，2-3 天可完成全部系年标注。
